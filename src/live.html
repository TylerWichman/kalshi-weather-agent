Connect the Refresh button

The button asks GitHub to fetch fresh prices right away. GitHub only allows that with a token. You need to do this once per browser.

  1. Open GitHub → New fine-grained token.
  2. Name it, for example dashboard refresh, and pick an expiration.
  3. Repository access: Only select repositories → kalshi-weather-agent.
  4. Permissions → Repository: Actions: Read and write and Contents: Read-only. Nothing else.
  5. Generate it, copy it and paste it here.

The token is saved only in this browser, for tylerwichman.github.io. It is never written to the repo or sent anywhere except api.github.com. It can start, stop and read this repo's workflows. It can't edit code or files. To remove it, revoke it on GitHub or clear this site's data.
